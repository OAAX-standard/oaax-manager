# oaax-manager

Command-line tool (`oaax`) to pull OAAX toolchains and runtimes and convert a model with them, on any vendor, with one uniform command.

**Status: design phase, private until ready.** Nothing is implemented yet.

Planned commands: `oaax list`, `oaax pull <vendor>`, `oaax convert <vendor> model.onnx -o out/`, `oaax check <runtime.so>`.
`oaax run` follows once the OAAX client library exists.
